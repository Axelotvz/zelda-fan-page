# Archivos de Hyrule: The Legend of Zelda Fan Page

Sitio web de fans dedicado al universo de *The Legend of Zelda*. Recopila la historia de la saga, una enciclopedia del reino y los mitos fundacionales de las Diosas de Oro.

🔗 **Ver el sitio:** https://axelotvz.github.io/zelda-fan-page/

## Contenido

- **Inicio:** presentación del sitio y la música icónica de la saga.
- **Saga:** lista de los 21 juegos principales por fecha de lanzamiento.
- **Enciclopedia:** razas y pueblos, artefactos sagrados y bestiario.
- **Mitología:** la creación del mundo, la Trifuerza, Hylia y el ciclo eterno.

## Tecnologías

- HTML5
- CSS3
- GitHub Pages

## Objetivo del proyecto

Proyecto personal para practicar el desarrollo de un sitio multipágina: estructura semántica, navegación, publicación y control de versiones con Git.
